## 4. Technical SEO: Next.js Metadata API, Hreflang, Canonicals, XML Sitemap & `robots.txt`

*(For the complete 100/100 Lighthouse SEO architecture, CMS SEO Admin Tools, redirect manager, and `generateMetadata` implementation specification, see `19-ADVANCED-SEO-AND-SEO-MAINTENANCE.md`.)*

### 4.1 Bidirectional `hreflang` & Self-Referencing Canonicals (`SEO-001`, `SEO-002`)
Every page pair resolves metadata dynamically from Payload CMS via Next.js `generateMetadata()`, outputting three `<link rel="alternate" hreflang="...">` tags and one self-referencing `<link rel="canonical">` tag in `<head>`. Example for `/services/brand-identity`:
```html
<!-- On https://<DOMAIN>/services/brand-identity -->
<link rel="canonical" href="https://<DOMAIN>/services/brand-identity" />
<link rel="alternate" hreflang="ar-SA" href="https://<DOMAIN>/services/brand-identity" />
<link rel="alternate" hreflang="en" href="https://<DOMAIN>/en/services/brand-identity" />
<link rel="alternate" hreflang="x-default" href="https://<DOMAIN>/services/brand-identity" />
```

### 4.2 Dynamic XML Sitemap (`src/app/sitemap.ts`) & `robots.txt` (`src/app/robots.ts`) (`SEO-002`)
- **Dynamic XML Sitemap (`/sitemap.xml`):** Generated dynamically by Next.js `sitemap.ts` querying Payload CMS Local API for all records where `_status === 'published'` and `seo.noIndex !== true` across both Arabic (`/`) and English (`/en/`), with `alternates.languages` (`ar-SA`, `en`) and accurate `lastModified` timestamps. Revalidated automatically via `revalidateTag('sitemap')` whenever any page, service, package, project, city, or blog post is published or unpublished.
- **Dynamic `robots.txt` (`src/app/robots.ts`):**
  - Production: Allow all search crawlers (`User-agent: * / Allow: /`), Disallow `/admin`, `/api`, and `/_next/data/`, and reference `Sitemap: https://<DOMAIN>/sitemap.xml`.
  - Staging / Preview environments (`VERCEL_ENV !== 'production'` or `APP_ENV !== 'production'`): Automatically return `Disallow: /` and `X-Robots-Tag: noindex, nofollow` so staging URLs never leak into Google indices.

### 8.2 Strict Non-Trailing-Slash Policy (`AUD-035`)
- `next.config.mjs` enforces `trailingSlash: false`. All internal links, `sitemap.ts` entries, `BreadcrumbList` JSON-LD `item` URLs, `canonical` tags, and `hreflang` URLs strip trailing slashes on every route except the root Arabic homepage (`https://<DOMAIN>`), with the English homepage strictly normalized to `https://<DOMAIN>/en` (never `/en/`).

### 8.3 Per-Locale Sitemap & `hreflang` Reciprocity Rule (`AUD-002`)
- `sitemap.ts` and `generatePageMetadata()` evaluate `_status === 'published' && doc.translationStatus?.[locale] === 'published' && doc.seo?.[locale]?.noIndex !== true` independently for `ar` and `en`. An untranslated or `noIndex` English route is never emitted in `sitemap.xml` and never referenced in `<link rel="alternate" hreflang="en">`.

### 8.4 City Page Schema.org `Service` (`areaServed`) & Anti-Doorway Gate (`AUD-036`, `AUD-037`)
- City pages (`/city/[slug]`) emit `@type: "Service"` referencing `@id: "https://<DOMAIN>/#organization"` as `provider` with `areaServed: { "@type": "City", "name": ..., "containedInPlace": ..., "geo": { "@type": "GeoCoordinates", ... } }`—never fabricating branch `LocalBusiness` street addresses.
